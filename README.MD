# Node.js for armv7

Since node for armv7 is not officially supported anymore (v24+), I decided to try to make it myself.

It required creating patch for v8 engine, and node crates.

## Download
Go to [releases](https://github.com/4meters/node-for-armv7/releases)

## How to build
Run:


`sudo build-for-armv7.sh`
